# Van Ginkel Houtbouw

WordPress maatwerkthema voor Van Ginkel Houtbouw.

## Doel

Een luxe, strak en verfijnd WordPress-thema met ACF-aansturing, pagina-templates en een eerste 3D-basis voor veranda/houtbouwbeleving.

## Structuur

Het thema staat in:

```text
wp-content/themes/vanginkelhoutbouw/
```

Plaats deze map in dezelfde locatie binnen WordPress en activeer het thema via **Weergave > Thema's**.

## Vereisten

- WordPress
- Advanced Custom Fields of Advanced Custom Fields Pro
- PHP 8.1+

## Eerste templates

- Home
- Standaard contentpagina
- Contact
- 3D configurator startpagina

## Werkwijze

Wijzig bestaande bestanden direct. Maak geen dubbele fix-bestanden zoals `bestand-fix.php` of `bestand-v2.php`.
